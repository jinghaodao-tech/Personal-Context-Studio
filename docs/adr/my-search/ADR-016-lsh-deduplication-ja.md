# ADR-016: LSHによる記事重複排除

## 背景

記事の重複排除は、これまで全ての記事ペアでshingleのJaccard類似度を計算していました。そのため本番経路がO(n^2)になっていました。

## 決定

決定的なMinHash LSHインデックスへ変更します。署名は64通り、16バンド×4行で構成します。LSHで候補ペアを絞り込み、最終的な重複判定は設定された閾値で正確なJaccard類似度を計算します。

exact全件比較を基準にした重複ペア再現度85%以上を回帰条件とします。exact基準実装は評価専用で、本番パイプラインでは使用しません。

## 結果

- 特徴量計算を除くインデックス構築は概ねO(n)です。
- 全件重複排除は平均候補数をcとすると概ねO(nc)です。
- ハッシュ衝突は正確なJaccard比較を増やすだけで、衝突だけで重複確定はしません。
- 再現度の目標はLSHパラメータから推測せず、決定的な回帰テストで測定します。
- ヒープ使用量は別ADR-017で扱い、数万件規模までは最適化を保留します。

## 撤回条件

実データで重複ペア再現度が85%未満になった場合は、署名数・バンド数を増やすか、対象コーパスの規模に応じて一時的にexactフォールバックを使います。閾値を黙って下げて対応しません。

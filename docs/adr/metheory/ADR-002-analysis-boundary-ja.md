# ADR-002: MeTheoryは記録作成ではなく分析を担う

## 背景
Personal Context Studioと各種エディターは、記録を快適に作成し、人が読める形で保存することに適している。

## 決定
記録レイヤーはPCSまたはMarkdownとする。MeTheoryは比較、Evidence、実験、ユーザーが確認したSelf Model提案を担う。Entryを暗黙に実験データへ変換してはならない。

## 代替案
すべての作成機能をMeTheoryへ移す、1つのデータベースを共有する、すべてのノートを自動抽出して分析する。

## 影響
境界を説明しやすく複数クライアントに対応できる一方、連携側は有効なSnapshotを提供する必要がある。

## 撤回方法
置き換えるソース契約と明示的な移行計画を用意した場合に限り変更する。

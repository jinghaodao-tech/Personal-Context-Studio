# ADR-011: 大規模標本の有意性フォールバックと候補監査

## 背景
完全置換検定は組合せ爆発する。大きなコホートで`null`を返すと、データが増えただけで比較を捨てることになる。候補が品質ゲートか統計的有意性のどちらで落ちたかも監査できなければならない。

## 決定
200,000割当までは完全置換検定を使い、それを超えたら10,000回の決定論的Monte Carlo置換検定とplus-one方式のp値を使う。方法は`monte_carlo_permutation`として保存し、完全検定とは表示しない。二値結果は正確な超幾何計算を使う。

候補監査には比較ファミリー数、各品質ゲート通過数、有意性で棄却された数、表示上限前の採用数を含める。連続量は値域ではなくプール標準偏差による標準化平均差を使う。コホート境界は`range_midpoint`、`observed_median`、`fixed_threshold`から選び、PCSの連続機械計測は`observed_median`を使う。

## 代替案

- 検定が大きくなったら`null`を返す。
- 実データで候補が出るまで閾値を緩める。
- 非決定論的な統計フォールバックを使う。
- 監査を結果ではなくログだけに残す。

これらは、原因の切り分けと再現性を損なうため採用しない。

## 影響
大規模コホートも明示的にラベル付けされた近似法で分析できる。数値効果は恣意的な管理範囲に依存しない。監査によって候補0件の原因を説明できるが、Monte Carlo結果は近似であり、実データの結論にはレビューが必要である。

## 撤回方法
回帰Fixtureを備えた新しいバージョン付き評価ポリシーを導入し、既存監査スキーマを保持する。閾値、p値法、コホート境界を暗黙に変更してはならない。

# ADR-005: 文章生成より先に決定論的評価を行う

## 背景
言語モデルにEvidenceの強さ、因果関係、最終的なSelf Model更新を決めさせてはならない。

## 決定
候補の統計量、データ品質、欠損、遵守状況、実験ステータスはTypeScriptのルールで計算する。ローカルAIは計算済み結果の文章化だけを行い、DTO検証を通過しなければならない。フォールバック文は決定論的に生成する。

## 代替案
AIに元記録を評価させる、クラウドモデルを既定にする、自由記述の結論を許可する。

## 影響
結果をテストでき、オフラインでも利用できる一方、表現力は低くなる。

## 撤回方法
評価器の契約を変更せず、検証済みの新しい説明プロバイダーを追加する。

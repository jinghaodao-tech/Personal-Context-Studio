# ADR-004: 分析履歴を不変にする

## 背景
新しいSnapshotで結果が変わっても、ユーザーが以前見た結果を消してはならない。

## 決定
`pcs_analysis_runs`に、`snapshotId`、profile、期間、スキーマバージョン、ソースID、ソースフィンガープリント、契約ハッシュ、簡潔な結果概要を保存する。同じSnapshotは冪等に扱い、新しいSnapshotでは新しい実行履歴を作る。

## 代替案
最新結果だけを保持する、1行だけを更新する、候補テキストだけを保存する。

## 影響
履歴を監査でき、古さの検証にも対応できる。分析実行ごとに保存領域は増えるが、元の記録は複製しない。

## 撤回方法
Provenanceとタイムラインイベントを保持する、バージョン管理された保持または圧縮ポリシーを追加する。

# ADR-013: 評価器の変更より先に再現性を確認する

## 背景

PCSの実データ期間は、候補ペア、コホート処理、期間、効果量の表示方法を開発しながら繰り返し確認しました。同じ発見データを見た後で評価器を変更すると、結果の再現性が分からなくなり、発見と検証が混ざります。

## 決定

現在の発見結果を良く見せることだけを目的に、評価器の閾値、候補の意味、または有意性の解釈を変更しません。現行の決定的な評価器を維持し、現在の結果は発見の根拠として扱います。評価器を変更する場合は版を付け、元の結果を残したまま、独立した期間で評価します。

比率、層別、相関などの記述的な頑健性診断は追加できます。ただし、それによって発見期間が検証期間や再現期間に変わることはありません。

## 結果

- 候補が出ない、または結論が保留のままでも、発見結果を合わせるために調整しません。
- 重複しない新しい期間で、同じ方向が再現するかを確認できます。
- 将来の評価器変更を、既存の基準結果と比較できます。

## 撤回条件

独立した再現期間、または対象となる測定クラスに対して現行評価器が不適切だと示す版管理された方法レビューが得られた場合に、再検討します。

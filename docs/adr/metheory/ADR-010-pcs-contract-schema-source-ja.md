# ADR-010: 公式PCSパッケージを分析契約の正本とする

## 背景
PCS分析Snapshotはリポジトリ間で共有される。ローカルに重複したスキーマを持つと、Personal Context Studioの契約とずれる可能性がある。

## 決定
`personal-context-studio/integration-contracts`パッケージを、Snapshotの形、スキーマバージョン、契約リビジョンの唯一の正本とする。MeTheoryはAPI境界と分析境界で、その実行時バリデーターとバージョン定数をimportする。旧`schemas/pcs-analysis-snapshot-v2.schema.json`は重複定義だったため削除し、Fixtureも公式パッケージで検証する。

## 代替案

- MeTheoryに第2のJSONスキーマを残す。
- 各リポジトリで契約を独立生成する。
- バージョンなしJSONを受け取り、項目を場当たり的に検証する。

いずれも契約のずれや暗黙の再解釈を許すため採用しない。

## 影響
契約変更は公式パッケージとロックされた依存バージョンを通じて調整する。ランタイムと検証が同じバリデーターを使い、Fixtureは具体例として残せる。

## 撤回方法
新しいバージョン付き契約の正本を定め、両リポジトリを同時に移行する。管理されない重複スキーマを再導入してはならない。

# ADR-007: SQLiteマイグレーションをバージョン管理する

## 背景
起動時に実行する`ALTER TABLE`は監査しにくく、デプロイ途中で失敗する可能性がある。

## 決定
`apps/api/src/db/migrate.ts`が`schema_migrations`の順序付き・冪等なマイグレーションIDを管理する。構造変更はトランザクション内で実行し、繰り返しても安全にする。

## 代替案
手動SQLコマンド、変更され続ける単一スキーマファイル、リクエスト起動時のバージョンなし`ensureColumn`呼び出し。

## 影響
マイグレーション履歴を確認でき、失敗時は起動を止められる。特殊な互換コードは段階的に整理する必要が残る。

## 撤回方法
前方移行を追加し、過去のマイグレーションIDは不変に保つ。

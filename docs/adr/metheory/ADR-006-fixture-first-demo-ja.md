# ADR-006: ローカルFixtureを優先するデモ

## 背景
PCSやローカルAIが利用できない場合でも、レビュアーが再現できるフローが必要である。

## 決定
`npm run demo`は、`fixtures/pcs-analysis-snapshot-v2.json`と`data/demo.sqlite3`を使うローカルAPIとDemo Webを起動する。実PCS接続はlocalhostでのみ利用できる任意モードとする。

## 代替案
起動中のPCSを必須にする、クラウドのデモ用データベースを使う、スクリーンショットだけを使う。

## 影響
デモを繰り返し実行でき、プライバシーも守れる。これは本番デプロイでも統合テストの代替でもない。

## 撤回方法
Fixture契約を維持したまま、文書化された実接続手順を追加する。決定論的な経路を削除してはならない。

# ADR-003: 候補ペアの明示的なAllowlist

## 背景
自由記述のラベルだけでは、意味的に有効な比較であることを十分に示せない。

## 決定
PCS経路の候補生成では、バージョン管理されたAllowlistと条件・結果の明示的なロールペアを必須とする。既存分析のために`candidate-pair-v1`は残し、`candidate-pair-v2`では機械計測ペアと`time_of_day -> focus`比較を追加する。不明、未確認、除外、互換性のないフィールドは理由を表示して除外する。

## 代替案
ラベルからロールを推測する、すべてのペアを比較する、AIにペアを選ばせる。

## 影響
候補数は減るが、各候補を説明可能かつ再現可能にできる。

## 撤回方法
テストとデータレビューを伴う新しいAllowlistバージョンを公開する。古いバージョンの意味を変更してはならない。

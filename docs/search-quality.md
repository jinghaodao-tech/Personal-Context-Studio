# PCS検索品質の測定

PCSの文書検索は、全文一致の`rank`と記録の新しさを混ぜたhybrid順序を使う。

```sql
(rank * 0.8) - (julianday(recorded_at) * 0.000001)
```

`0.8`は全文一致を主信号として維持する重み、`0.000001`は同程度の一致度で新しい記録を優先するための小さなタイブレーカーである。係数を「妥当」とみなすだけにせず、固定クエリセットでP@1とMRRを測る。

## 評価方法

`test/search-quality.test.ts`が、PCSの実HTTPエンドポイントに5文書を登録し、4つの代表クエリを検索する。各クエリに正解文書を定義し、次を計算する。

- **P@1**: 1位が正解だったクエリの割合
- **MRR**: 最初の正解順位の逆数の平均

v1の品質床はP@1 0.75以上、MRR 0.875以上。検索式を変更した場合は、このテストと係数の根拠を同時に更新する。
